# 📱 Cryptocurrency App

A **Flutter-based mobile app** that provides real-time cryptocurrency prices, detailed coin information, and interactive charts. Built with a clean and intuitive UI, the app offers features like personalized watchlists and market insights for quick, informed decisions.



## 🚀 Features

- 🔍 Real-time cryptocurrency data
- 📈 Interactive charts and price history
- 📋 Watchlist to track favorite coins
- 🌙 Light & dark mode support
- 🔄 Pull-to-refresh functionality
- 📱 Optimized UI for both Android and iOS

## 📦 Installation

1. **Clone the repository**  
   ```
   git clone https://github.com/meet-makadiya/Cryptocurrency_App.git
   cd Cryptocurrency_App
    ```

2. **Install dependencies**

   ```bash
   flutter pub get
   ```

3. **Run the app**

   ```bash
   flutter run
   ```
